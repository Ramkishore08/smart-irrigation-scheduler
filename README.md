# Smart Irrigation Scheduler

## Project Description
Smart Irrigation Scheduler is a rule-based web application developed using Python and Flask.

It helps generate irrigation decisions based on:
- Soil Moisture
- Crop Stage
- Weather
- Water Availability
- Field Priority

## Technologies Used
- Python
- Flask
- HTML
- CSS
- Bootstrap
- SQLite
- Pandas
- CSV

## Main Features
- User Registration and Login
- Smart Irrigation Decision
- Recommended Water Calculation
- Water Saved Calculation
- Fairness Information
- Irrigation History
- Analytics Report
- CSV Report Download
- Admin Override

## How to Run

Install the required packages:

pip install -r requirements.txt

Run the application:

python app.py

Open in browser:

http://127.0.0.1:5000/

## Project Type
This is a rule-based intelligent irrigation scheduling system.
It is not a Machine Learning model.
